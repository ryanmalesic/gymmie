# Prisma PostgreSQL setup

Use `provider = "postgresql"` for PostgreSQL 18; the server version does not change the Prisma provider name. Configure `DATABASE_URL` for runtime and `DIRECT_URL` when a pooler should be used by Prisma CLI migrations.

Use `prisma-client` with an explicit output path for new Prisma 7 projects. The PostgreSQL runtime client uses `@prisma/adapter-pg` and `pg`. Load environment variables in `prisma.config.ts` and keep credentials out of source control.

For model IDs generated by PostgreSQL, use a string field with a reviewed `@default(dbgenerated("..."))`, create the function in an earlier migration, and ensure the application does not supply a competing ID.

Reference: https://www.prisma.io/docs/orm/overview/databases/postgresql and https://www.prisma.io/docs/orm/prisma-schema/overview/generators
